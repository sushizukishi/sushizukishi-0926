# モチベーショングラフ

幼少期から現在までの出来事を時期ごとに振り返り、モチベーションの波をグラフに描くWebアプリです。
**経験 → 感情 → 価値観** の順にたどり、自分が大切にしている価値観を見つけて言葉にすることをゴールにしています。

- ログイン・インストール不要。URLを開けばすぐ使えます
- 入力内容はブラウザの中（localStorage）だけに保存され、外部には送信しません。傾向の分析も端末の中で行います
- 入力中の内容も自動保存されるので、途中で閉じても消えません

## 機能

| 機能 | 内容 |
| --- | --- |
| ガイド入力 | 幼少期 → 小学校 → 中学校 → 高校 → 大学・専門 → 社会人（3年ごと）の順に登録。件数は自由、スキップ・戻る可。社会人は「次の3年へ」で延ばせる |
| 出来事の登録 | 【経験】時期・スコア（-5〜+5、言葉ラベル付きスライダー）は必須。出来事名・年齢・メモは任意 |
| 感情タグ | 【感情】嬉しい・誇らしい・悔しい・不安など。任意・複数可 |
| 価値観タグ | 【価値観】その出来事で満たされていた／損なわれていたもの（成長・つながり・自由など、自分で追加も可） |
| 価値観を見つける | 気づき（示唆と問い）、価値観の候補（満たされて上がった・損なわれて下がった大きさの比較と、経験→感情→価値観のつながり）、感情の傾向を表示。候補をグラフ上で強調表示できる |
| わたしの価値観 | 候補から最大3つ選び、自分の言葉で書き残す。画像保存にも入る |
| グラフ表示 | 横軸＝時期、縦軸＝スコアの折れ線。点をタップすると詳細を表示。入力中の値は点線の点でプレビュー |
| 編集・削除 | 一覧・グラフの点・価値観の候補から編集・削除 |
| 画像で保存 | グラフをPNG（出来事名・わたしの価値観つき）で保存 |
| バックアップ | データをJSONファイルで書き出し・読み込み（端末の移行用） |

「上がったときにも下がったときにも出てくる価値観」を、特に大切なものの有力候補として示します。
満たされると上がり、損なわれると下がるものほど、その人にとって大事だと考えるためです。

年齢を入力した出来事は時期の年齢幅の中に、未入力の出来事は時期内で均等に並びます。

## 使い方（開発）

ビルド不要の静的ファイル（`index.html` / `style.css` / `app.js`）だけで動きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 公開

静的ホスティングならどこでも公開できます。例えば GitHub Pages なら、リポジトリの
Settings → Pages で公開ブランチとルートフォルダ（`/`）を選ぶだけです。
