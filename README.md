# モチベーショングラフ

幼少期から現在までの出来事を時期ごとに振り返り、モチベーションの波をグラフに描くWebアプリです。
上がった・下がった理由をメモして見返すことで、自分が大事にしている価値観に気づくきっかけをつくります。

- ログイン・インストール不要。URLを開けばすぐ使えます
- 入力内容はブラウザの中（localStorage）だけに保存され、外部には送信しません
- 入力中の内容も自動保存されるので、途中で閉じても消えません

## 機能

| 機能 | 内容 |
| --- | --- |
| ガイド入力 | 幼少期 → 小学校 → 中学校 → 高校 → 大学・専門 → 社会人 の順に、各時期1〜3件を登録（スキップ・戻る可） |
| 出来事の登録 | 時期・スコア（-5〜+5、言葉ラベル付きスライダー）は必須、出来事名・年齢・理由メモは任意 |
| グラフ表示 | 横軸＝時期、縦軸＝スコアの折れ線。点をタップすると理由メモを表示。入力中の値は点線の点でプレビュー |
| 編集・削除 | 一覧またはグラフの点から編集・削除 |
| 画像で保存 | グラフをPNG（1200×630、出来事名つき）で保存 |
| バックアップ | データをJSONファイルで書き出し・読み込み（端末の移行用） |

年齢を入力した出来事は時期の年齢幅の中に、未入力の出来事は時期内で均等に並びます。

## 使い方（開発）

ビルド不要の静的ファイル（`index.html` / `style.css` / `app.js`）だけで動きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 公開

静的ホスティングならどこでも公開できます。例えば GitHub Pages なら、リポジトリの
Settings → Pages で公開ブランチとルートフォルダ（`/`）を選ぶだけです。
